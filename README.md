# 老祖法宝模拟器 · 觉醒版

更新日期：2026-10-03。原作者：[fradwow/laozu-solver](https://github.com/fradwow/laozu-solver)，基线提交 `c3f12d16cc95e1ceb8509cf62296653bba075729`。原仓库公开单文件构建产物，没有原始前端工程。本地以确定性的补丁脚本继续维护，保留作者署名、原版界面、截图识别、背包编辑、方案保存、多线程退火和主线程回退。

## 打开

在线使用：[hekunwang.github.io/laozu-solver](https://hekunwang.github.io/laozu-solver/)。本仓库 fork 自原作者仓库，由 GitHub Pages 发布 `main` 分支的根目录。

双击本目录的 `打开法宝模拟器.command`，或直接用浏览器打开 `index.html`。网页包含全部脚本、数据和 Worker，可离线运行，无须安装依赖或登录游戏。收藏、持有清单和觉醒等级保存在当前浏览器的本地存储；换浏览器或地址不会自动同步。

可选本地预览：在本目录执行 `node serve.cjs`，打开 <http://127.0.0.1:18764>。仅监听本机。

- 截图导入自动识别红宝右下角的觉醒火焰及数字，独立于下方共鸣数字。逐件展示角标裁切和等级，可手动校正；模糊、低分辨率或截断而无法确定时，必须确认后才能导入。全程在浏览器本地处理。

- 计入自身基础三围、相邻技能和全局形态光环；有光环时全量重算，避免增量缓存漏算放入/移除光环来源后的变化。

- 计算时间默认20秒，旧自动存档首次升级迁移为20秒，之后自行选择的时间正常保存；计算完成或主动停止得到有效结果后自动显示最终摆盘。更新日志保留上游历史并加入本版两项主要改动。
- 同步官方快照中 8 条已调整的旧技能数值，包括金系碎甲剑/龙渊增伤、火系炽影/烈阳增伤、巨灵防御加成；详情说明同步修正。

## 维护与重建

`upstream.html` 和 `upstream-bundle.js` 保留原版；`build-catalog.py` 从已解码官方表构建目录和觉醒数据；`patch-upstream.cjs` 将这些数据接入原版网页与内嵌 Worker；`patch-instance-engine.cjs` 与 `patch-instance-ui.cjs` 处理逐件觉醒、保存和角标；`awakening-recognizer.js` 与 `patch-awakening-import.cjs` 处理截图识别和确认；`patch-mobile-import.cjs` 和 `mobile-ui.css` 维护截图导入的移动端布局；`patch-interaction.cjs` 维护更新日志、默认时长与计算结束跳转；`build.cjs` 输出独立 `index.html`。补丁遇到基线结构变化会报错，不会静默套用。

```sh
# 已包含目录数据；更新配置表时才需用已选定的 Python 3 解释器运行 build-catalog.py。
node build.cjs
```

仓库已包含重建所需的解码配置表，不需要原始资源导出工具。维护者若更新快照，需自行提供对应版本的配置解码工具；本地使用的工作区导出器不随此仓库发布。新版本若加入全新法宝或机制，还需同步目录/形状与模型，不能仅改版本号。
