## 打开

在线使用：[hekunwang.github.io/laozu-solver](https://hekunwang.github.io/laozu-solver/)。本仓库 fork 自原作者仓库，由 GitHub Pages 发布 `main` 分支的根目录。

双击本目录的 `打开法宝模拟器.command`，或直接用浏览器打开 `index.html`。网页包含全部脚本、数据和 Worker，可离线运行，无须安装依赖或登录游戏。收藏、持有清单和觉醒等级保存在当前浏览器的本地存储；换浏览器或地址不会自动同步。

可选本地预览：在本目录执行 `node serve.cjs`，打开 <http://127.0.0.1:18764>。仅监听本机。

## 计算口径与尚待核验

这是法宝属性战力优化器，不是战斗模拟器；不包含技能回合、共鸣总战力、毕业评分。退火输出是当前最高解，没有全局最优证明。

2026-10-02 同局换摆法的面板反例已确认：TapTap 第二张与第三张使用相同法宝，攻击和速度不变，第三张防御 +516、生命 -49,816，游戏总战力却 +21,443。即使直接代入真实面板三围，当前 `10×攻击 + 10×防御 + 0.2×生命` 仍给出 -4,803.2，排序相反。因此本工具的「战力最大化」是法宝模型分最大化，不能当成游戏面板总战力最大化。固定的共鸣战力不能解释此差异。原版简化目录未保留官方属性折算的 `arrPowerAttr/arrPowerParam`，但已确认的客户端折算用于师父/功法展示，弟子面板战力为服务端下发，尚未还原其公式，不能直接套用这些数组宣称已修正。

数据来自保存的 9 月 24 日官方资源，不能保证已包含此后的所有游戏更新。`data/export-manifest.json` 记录原始资源文件哈希，`data/manifest.json` 记录本地数据哈希。应用无需登录游戏，清单、截图识别模板和方案均保存在当前浏览器，不上传至本仓库。

觉醒等级和效果来自官方配置，技能替换已通过程序集 IL 核对。形态光环的模型按文案作为基础属性百分比，与星级、天赋、自身觉醒加法合并后取整，再应用邻接百分比。同款多件按独立来源叠加并排除来源那一件；这两项乘算/排除细节尚未用实时游戏面板验证。网页详情注明该限制。4、5 级在此快照中为「敬请期待」，不会启用预留数据。

## 维护与重建

`upstream.html` 和 `upstream-bundle.js` 保留原版；`build-catalog.py` 从已解码官方表构建目录和觉醒数据；`patch-upstream.cjs` 将这些数据接入原版网页与内嵌 Worker；`patch-instance-engine.cjs` 与 `patch-instance-ui.cjs` 处理逐件觉醒、保存和角标；`awakening-recognizer.js` 与 `patch-awakening-import.cjs` 处理截图识别和确认；`build.cjs` 输出独立 `index.html`。补丁遇到基线结构变化会报错，不会静默套用。

```sh
# 已包含目录数据；更新配置表时才需用已选定的 Python 3 解释器运行 build-catalog.py。
node build.cjs
node tests/engine-parity.cjs
node tests/instance-awakening.cjs
node tests/awakening-recognition.cjs
```

仓库已包含重建所需的解码配置表，不需要原始资源导出工具。维护者若更新快照，需自行提供对应版本的配置解码工具；本地使用的工作区导出器不随此仓库发布。新版本若加入全新法宝或机制，还需同步目录/形状与模型，不能仅改版本号。
